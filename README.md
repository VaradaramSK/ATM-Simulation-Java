# 🏧 ATM Simulation System – Java

## 📌 Aim
To develop a Java-based ATM Simulation System that replicates basic banking operations, allowing users to perform transactions through a simple and interactive console-based application.

## 📝 Project Description
The ATM Simulation System is a console-based application developed using Java to simulate the basic functionalities of an Automated Teller Machine (ATM). It enables users to perform essential banking operations such as checking account balance, depositing money, and withdrawing cash.

The project demonstrates the practical implementation of Java programming concepts, Object-Oriented Programming (OOP), methods, conditional statements, and transaction management.

## ✨ Features
- ✅ Account Balance Inquiry
- ✅ Cash Withdrawal
- ✅ Cash Deposit
- ✅ Interactive Console Menu
- ✅ Basic Transaction Handling
- ✅ Input Validation

## ⚙️ Application Workflow
1. Launch the ATM Simulation application.
2. Display the available banking operations.
3. Select the required transaction.
4. Enter the necessary amount or details.
5. Process the transaction.
6. Display the updated account balance.
